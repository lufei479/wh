条件结构：if / else if / else成绩等级评定

输入一个 0~100 的分数，程序按区间自上而下依次判断，命中第一个成立的条件后输出等级。

if (score >= 90) { grade = "优秀" } else if (score >= 80) { grade = "良好" } else if (score >= 60) { grade = "及格" } else { grade = "不及格" }

条件结构：switch / case数字转星期

switch 用严格相等（===）把表达式的值与各 case 逐一比对，匹配后执行并 break 跳出，default 兜底。

switch (day) { case 1: name = "星期一"; break; case 6: name = "星期六"; break; ... default: name = "输入无效"; }

循环结构：for 嵌套九九乘法表

外层 for 控制行（被乘数 1~9），内层 for 控制列，两层循环共执行 81 次拼接出整张表。

for (let i = 1; i <= 9; i++) { for (let j = 1; j <= i; j++) { output += j + "×" + i + "=" + (i * j) + " "; } }

循环结构：while1 到 N 累加

while 先判断条件再执行循环体，条件不成立时退出；下方实时展示每一步累加的过程。

let sum = 0, k = 1; while (k <= n) { sum += k; k++; }
