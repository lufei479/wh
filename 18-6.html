图一 · 业务流程图（flowchart）

用户提问到答案返回的完整链路：意图分支 → RAG 检索生成 → 质量校验 → 转人工兜底

flowchart TD
    A([用户提问]) --> B[多轮会话管理
补全上下文]
    B --> C{NLU 意图识别}
    C -->|常见业务咨询| D[问题改写
Query Rewrite]
    C -->|闲聊寒暄| E[闲聊话术库
直接回复]
    C -->|敏感或投诉| H[转接人工坐席]
    D --> F[(向量数据库
Top-K 召回)]
    F --> G[Rerank 精排
取前 N 片段]
    G --> I[LLM 生成答案
附引用溯源]
    I --> J{质量校验
置信度是否达标}
    J -->|达标| K[返回答案给用户]
    J -->|不达标| H
    K --> L[用户反馈评价]
    L --> M[(标注回流
知识库持续优化)]
    M -.-> F

图二 · 数据库 ER 图（erDiagram）

智能客服核心数据模型：用户、会话、消息、知识条目与反馈记录的实体关系

erDiagram
    USER ||--o{ SESSION : "发起"
    SESSION ||--o{ MESSAGE : "包含"
    MESSAGE ||--o| FEEDBACK : "获得"
    USER ||--o{ FEEDBACK : "评价"
    CATEGORY ||--o{ KB_ENTRY : "归类"
    KB_ENTRY ||--o{ MESSAGE_CHUNK : "被引用"
    MESSAGE }o--o{ KB_ENTRY : "召回关联"

    USER {
        bigint user_id PK
        varchar nickname
        varchar channel "渠道 web 小程序"
        datetime created_at
    }
    SESSION {
        bigint session_id PK
        bigint user_id FK
        varchar status "进行中 已结束"
        varchar intent "意图标签"
        datetime started_at
    }
    MESSAGE {
        bigint message_id PK
        bigint session_id FK
        varchar role "user bot agent"
        text content
        decimal confidence "置信度"
        datetime sent_at
    }
    FEEDBACK {
        bigint feedback_id PK
        bigint message_id FK
        bigint user_id FK
        tinyint score "赞 1 踩 0"
        text comment
    }
    KB_ENTRY {
        bigint entry_id PK
        bigint category_id FK
        varchar title
        text content
        vector embedding "语义向量"
        datetime updated_at
    }
    CATEGORY {
        bigint category_id PK
        varchar name
        bigint parent_id FK
    }

互动 · 修改 Mermaid 源码实时渲染

把流程图源码粘贴到下方文本框（或修改默认内容），点「重新渲染」即时生成新图

// mermaid 本地引入与初始化（与 echarts 同目录 cdn/）
<script src="./cdn/mermaid.min.js"></script>
mermaid.initialize({ startOnLoad: true, theme: "base" });
// 互动渲染：mermaid.render 返回 { svg }，写入容器
const { svg } = await mermaid.render("wh_live_" + Date.now(), wh_code);
