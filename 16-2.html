创建与访问点语法 · 方括号语法

对象用花括号创建，属性用「键值对」描述。点写法简洁，方括号可以用变量当键名。

const wh_student = { name: "小明", age: 19, major: "网页设计", hobby: "打篮球" };

点语法

适合键名固定、合法的场景。

方括号语法

键名可拼接、含空格或来自变量时只能用它。

增 · 改 · 删添加属性 · 修改 · delete

直接赋值即可新增或修改属性，delete 运算符移除属性。档案卡会高亮刚刚变化的行。

点击按钮观察档案卡变化。

遍历对象for...in · Object.keys / values

for...in 依次取出每个键名，再用方括号取对应的值。

for (const wh_key in wh_student) { console.log(wh_key + " : " + wh_student[wh_key]); }
遍历结果会以标签形式展示在下方。

对象的方法方法与 this

属性值是函数时称为「方法」。方法里的 this 指向对象本身，于是能读到自己的属性。

wh_student.intro = function () { return "大家好，我是" + this.name + "，今年" + this.age + "岁，正在学" + this.major + "。"; };
点一下上面的按钮，小明会开口自我介绍。
