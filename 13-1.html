Font Awesome 字体图标

字体图标方式：引入本地 CSS 与 webfont 字体文件，用 <i class="fa-solid fa-xxx"> 显示图标

常用图标（fa-solid 实心）

图标本质是字体中的字符，可以通过 font-size 和 color 像文字一样控制。

字号缩放

字体图标随 font-size 缩放，任意尺寸都保持清晰。

font-size: 14px / 24px / 36px / 56px

颜色控制

图标是文字，直接用 color 即可着色。

color: #ef4444;

动画效果

配合 CSS 动画，让字体图标动起来。

.fa-spin { animation: fa-spin 2s infinite; }

本地文件结构

cdn/css/all.min.css —— 图标样式表（内含 @font-face 声明）

cdn/webfonts/fa-solid-900.woff2 / .ttf —— 实心图标字体

cdn/webfonts/fa-regular-400.woff2 / .ttf —— 常规图标字体

cdn/webfonts/fa-brands-400.woff2 / .ttf —— 品牌图标字体

页面通过 <link> 引入 CSS，浏览器加载 webfont 后按字符码渲染图标
