动手试一试

输入任意 JavaScript 值（数字、带引号的字符串、true、null、{ } 对象……），页面会解析并用 typeof 检测它的类型。

结果将显示在这里。
注意一个历史遗留问题：typeof null 的结果是 "object"，这是 JavaScript 自 1995 年延续至今的著名 Bug，出于兼容性考虑一直未被修复。判断 null 请直接使用 value === null。
