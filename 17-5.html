JavaScript 的两种定时器

setTimeout 一次性延时执行（用 clearTimeout 取消）｜ setInterval 循环定时执行（用 clearInterval 停止）

定时炸弹 · setTimeout 一次性

设定秒数后倒计时，时间一到触发一次爆炸动画

// id 用于取消
const id = setTimeout(fn, 秒数 * 1000);
clearTimeout(id);  // 引爆前拆除
💣
等待启动…

秒表与在线时钟 · setInterval 循环

每隔指定毫秒执行一次，直到 clearInterval 停止

const id = setInterval(fn, 1000);
clearInterval(id);  // 停止循环
00.0 秒表已停止 ｜ 时钟 --:--:--
