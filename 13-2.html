Lucide SVG 图标

SVG 方式：引入本地 lucide 脚本，把 <i data-lucide="xxx"> 渲染为内联 <svg> 元素

常用图标

每个图标最终都是一段独立的 SVG 代码，不依赖字体文件。

<i data-lucide="house"></i> + lucide.createIcons()
house
user
heart
star
mail
settings
search
bell
camera
music
map-pin
download

填充与线性风格

Lucide 默认是描边线性图标，通过 fill 属性可变为实心效果。

fill="currentColor"（实心） / 不填充（线性）
线性
实心
线性
实心

尺寸控制

SVG 通过 width / height 属性缩放，与字体大小无关。

width="16" / 28 / 40 / 60
16px
28px
40px
60px

颜色控制

SVG 使用 stroke="currentColor"，继承 CSS 的 color 属性即可换色。

color: #ef4444;（作用于 stroke）

描边粗细

通过 stroke-width 调整线条粗细，这是 SVG 图标独有的可定制性。

stroke-width: 1 / 2 / 3
stroke-width: 1
stroke-width: 2
stroke-width: 3

本地文件结构

cdn/js/lucide.min.js —— Lucide 浏览器脚本（UMD）

页面用 <script src="./cdn/js/lucide.min.js"> 引入本地脚本

脚本调用 lucide.createIcons()，把 data-lucide 占位元素替换为内联 SVG

复杂定制时也可直接手写 SVG 标签，无需脚本
