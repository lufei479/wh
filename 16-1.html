增删积木push / pop / shift / unshift

push 与 unshift 从尾部 / 头部加入积木，pop 与 shift 从尾部 / 头部取走，返回值是被取走的那块。

点击任意按钮，这里会显示执行的代码与返回值。

切分与拼接splice / slice / concat

splice 直接在原数组上动刀（增删都行），slice 只切出副本不动原数组，concat 拼接出新数组。

注意观察：slice 与 concat 不改变原数组。

查找与判断indexOf / includes

indexOf 返回元素的下标（找不到返回 -1），includes 只回答"有"还是"没有"。

试试查找"橙子"或一个不存在的水果。

变形金刚map / filter / reduce / sort / reverse / join

数字数组专用的三种高阶方法：map 逐个变形（1 变 1）、filter 用漏斗筛选、reduce 把全部压成一个值。

map / filter / reduce / join 返回新数组或新值，sort / reverse 会改变原数组。
